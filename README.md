# Auto configuração de sistema operacional

<https://www.debian.org/Pics/debian-logo-1024x576.png>

Este repositório contém minha configuração personalizada do Debian, partindo sempre de uma instalação "minimal" (ou seja, apenas o kernel e os pacotes essenciais, sem software pré-instalado). Os scripts aqui presentes facilitam a instalação do Desktop Environment GNOME e da coleção de programas que uso diariamente.
